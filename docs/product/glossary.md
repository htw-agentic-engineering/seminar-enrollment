## Begriffe

| Begriff | Bedeutung | Im Code |
| --- | --- | --- |
| Projektseminar | Eine Lehrveranstaltung mit begrenzter Teilnehmerzahl, die von einem Professor betreut wird und für die sich Studierende bewerben | `ProjectSeminar` |
| Bewerbung | Die verbindliche Einreichung der drei priorisierten Wünsche einschließlich Motivationsschreiben durch einen Studierenden | `Application` |
| Erstwunsch | Das vom Studierenden am höchsten priorisierte Projektseminar | `FirstChoice` |
| Zweitwunsch | Das zweithöchst priorisierte Projektseminar | `SecondChoice` |
| Drittwunsch | Das dritthöchst priorisierte Projektseminar | `ThirdChoice` |
| Motivationsschreiben | Text, den der Studierende zur Begründung seines Erstwunsches verfasst | `MotivationLetter` |
| Bewerbungsstatus | Aktueller Stand einer Bewerbung (z. B. Eingereicht, In Bearbeitung, Zugeteilt) | `ApplicationStatus` |
| Zuteilung | Die administrative Zuordnung eines Studierenden zu einem Projektseminar | `Assignment` |
| Platzkapazität | Maximale Anzahl an Studierenden, die ein Projektseminar aufnehmen kann | `Capacity` |
| Berechtigung | Recht eines Nutzers, das System zu nutzen (z. B. bestimmter Semesterstand) | `Eligibility` |
| S-Nummer | Hochschulinterne Benutzerkennung der Studierenden | `SNumber` |
| Seminarübersicht | Liste aller verfügbaren Projektseminare mit Titel, Nummer und betreuendem Professor | `SeminarOverview` |
| Seminarbeschreibung | Ausführliche Beschreibung eines Projektseminars, in der Regel als PDF bereitgestellt | `SeminarDescription` |
